# champions-teambuilder

#### Installation

Clone the Repository
```fish
git clone https://github.com/Syruppmaxr/champions-teambuilder
```
Navigate into "champions-teambuilder"
```fish
cd ~/champions-teambuilder/champions-teambuilder
```
Create a python virtual environment
```fish
python -m venv .venv
```
Activate the virtual environment
```fish
source .venv/bin/activate.fish
```
Install the project into the virtual environment
```fish
python -m pip install -e .
```
